# 말씀타자

성경 구절만으로 연습하는 한국어 타자연습 웹페이지입니다.

- 날짜에 따라 정해지는 오늘의 말씀
- 유명 구절 30개로 연습하는 단문, 여러 절을 이어 쓰는 장문 12편
- 책별 필터, 무작위 다음 말씀, 다시 쓰기
- 두벌식 자소 기준 타수, 입력 시도 기준 정확도, 시간, 진행률
- 한글 IME 조합을 고려한 입력, 오타 표시, 완주 결과
- 최근 50회 기록과 테마를 브라우저 로컬 저장소에 저장
- 모바일 레이아웃과 다크 모드

## 실행

```sh
python -m http.server 4173
```

브라우저에서 http://localhost:4173 으로 접속합니다. 모듈과 JSON을 사용하므로 HTML 파일을 직접 여는 대신 HTTP 서버를 사용합니다.

## 검사

```sh
npm ci
npm test
```

## 데이터 재생성

`tools/source.jsonl`에 [원본 데이터](https://raw.githubusercontent.com/crizin/bible-db/main/data/krv/krv_holybible.jsonl)를 내려받은 다음 `python tools/prepare-data.py`를 실행합니다.

## 배포

GitHub Pages의 `main` 브랜치 루트에서 정적 파일을 제공합니다. 서버·API 키·로그인은 필요하지 않습니다.

정확도는 확정된 새 입력의 정답 비율이며, 오타를 지워도 이전 오타는 기록에 반영됩니다. 타수는 현재 정확히 입력된 문자의 두벌식 자소 수를 실제 경과 시간으로 나눕니다. 기록은 이 브라우저에만 남으며, 사이트 데이터 삭제 시 함께 지워집니다. 오늘의 완주 횟수는 보관 중인 최근 50회 기록을 기준으로 합니다.

성경 번역본과 데이터 출처는 [NOTICE.md](./NOTICE.md)에 명시하였습니다.
